# agents-org

Claude Code 上で自律的にアプリケーション開発を進める **AI開発組織** の定義リポジトリ。

PO（プロジェクトオーナー）が自然言語で開発ゴールを与えると、オーケストレーターがタスクへ分解し、設計・実装・レビュー・テスト・ドキュメントの各エージェントへ割り当てて開発を進める — その組織構造そのものをここで定義する。

## 状態

**要件定義フェーズ。** 実行可能なコードはまだ無い。

## いま進めていること

要件定義書 §23 に従い、各エージェントの **入力・出力・エスカレーション条件** を順に確定している。
要件定義書に記載済みなのはミッションと責務までで、その先が未確定。

## 設計方針の要点

- Claude Code 標準機能（CLAUDE.md / Skills）を最大限使い、独自の設定ファイル機構を作らない
- オーケストレーターは司令塔に徹し、自分では実装しない
- 判断不能な事項は段階的にエスカレーションし、最終的に PO 確認待ちキューへ積む
- PO の回答待ちの間も、依存関係のないタスクは止めない
- 既存の Claude Code 拡張（Everything Claude Code / Superpowers 等）と共存する

詳細は要件定義書を参照。
